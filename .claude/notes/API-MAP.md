## ⚠ This app has no router enum, and one endpoint

`Scripts/scan-api-map.py` reports **0 endpoints**, and that is correct for what it looks for: it
discovers a router enum from `callAPI(path:method:)` call sites. This app has neither. There is one
network call, made with `String(contentsOf:)` against an HTML page, and the URL is built inside
`NetworkKit`.

Changing `CALL_FN` would not help — there is no router to discover. The rows below are therefore
**hand-maintained**, outside the generated region, and must be updated by hand when the network edge
changes. The generated region is left to the script so a later `--apply` does not fight this note.

## Endpoints — hand-maintained

| Method | Path | Screen | Caller | Dir |
|---|---|---|---|---|
| GET | `https://github.com/users/{username}/contributions` — **HTML page, not an API** | `ContributionsList` (via `ContributionsRow`) · `ContributionsGraphEntryView` | `GitHub.getContributions(for:)` | NetworkKit/Sources/NetworkKit/ |

**Response handling:** the HTML is parsed with SwiftSoup, selecting `td` elements and reading their
`data-date` and `data-level` attributes. There is no JSON, no versioned contract, and no error body.

## Gaps

| Finding | Where | Noted |
|---|---|---|
| **The only endpoint is an HTML scrape with no contract** | NetworkKit/Sources/NetworkKit/ | A GitHub markup change breaks every installed copy simultaneously. This is the concrete form of the missing-kill-switch risk in [GAPS.md](../../docs/GAPS.md) |
| **`String(contentsOf:)` is a synchronous, blocking call inside an `async` function** | NetworkKit/Sources/NetworkKit/ — `getContributions` | It blocks a cooperative-pool thread for the whole request rather than suspending. `URLSession.data(from:)` is the non-blocking equivalent. This is a genuine defect, not a style preference |
| Both consumers swallow the error | Contributions/List/ContributionsRowViewModel.swift · ContributionsWidget/ContributionsProvider.swift | `try? await GitHub.getContributions` at both sites — the §2.7 debt in [GAPS.md](../../docs/GAPS.md) |
| URLs are built inside features | Contributions/Settings/ · Contributions/List/ | `SettingsViewModel` and `ContributionsRowViewModel` construct URLs with `URL(string:)` directly. There is no router to name a case in. **A finding, not a violation** — the router rule lives in §6/§7, which this repo did not adopt |
| No timeout, retry, or cache policy | NetworkKit/Sources/NetworkKit/ | `String(contentsOf:)` exposes none of these |

**Never treat "never called" as "safe to delete".** A case can be reached through a variable, a
protocol witness, or a `#selector`-style indirection that no static scan sees. Any such list is a set
of candidates and must say so.

**Not checked:** whether GitHub's markup still matches the `td[data-date][data-level]` selector (that
needs a live request, which this command never makes); response sizes; and whether the widget and app
should share a cache, which is a design decision rather than a scan result.
